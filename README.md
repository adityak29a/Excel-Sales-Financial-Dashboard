Excel Sales & Financial Dashboard
An interactive Excel dashboard built to analyze transaction-level sales and financial performance across products, regions, departments, and payment methods.
Dashboard Preview
 
Project Overview
This project uses a dataset of 2,000 transactions to analyze revenue, expenses, profit, products, regions, departments, and payment methods.
The dashboard was built in Microsoft Excel using PivotTables, PivotCharts, and dashboard formatting to turn transaction-level data into management-friendly insights.
Tools & Skills
- Microsoft Excel
- PivotTables
- PivotCharts
- Data aggregation and analysis
- Dashboard design
- Business KPI analysis
- Data visualization
Dashboard Analysis
The dashboard includes:
- Total Profit by Payment Method
- Total Revenue by Product Line
- Number of Transactions by Region
- Revenue, Expenses & Profit by Department
- Average Expenses by Department
Key Dataset Fields
Transaction_ID, Transaction_Date, Revenue, Expenses, Profit, Category, Region, Department, Product_Line, Customer_Segment, Payment_Method, Discount
