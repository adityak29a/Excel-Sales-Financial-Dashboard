# 📊 Excel Sales & Financial Dashboard

## 📌 Project Overview

This project is an **Excel-based Sales & Financial Dashboard** designed to analyze business performance across revenue, expenses, profit, transactions, product lines, departments, regions, and payment methods.

The project uses **2,000 transaction records** and Excel PivotTables and charts to transform raw business data into meaningful insights and an easy-to-understand dashboard.

- Expenses

- Category
- Region
- Department
- Product Line
- Customer Segment
- Payment Method
- Discount

## 📊 Dashboard Analysis

The dashboard provides analysis of:

- Total Profit by Payment Method
- Total Revenue by Product Line
- Number of Transactions by Region
- Revenue, Expenses & Profit by Department
- Average Expenses by Department

## 🔑 Key Insights

- **Total Revenue:** 53,965,575
- **Total Expenses:** 33,472,046
- **Total Profit:** 20,493,529
- **Total Transactions:** 2,000

### Payment Method
Cash generated the highest profit with **9,013,666**.

### Product Line
Healthcare generated the highest revenue with **21,863,582**.

### Department
R&D generated the highest revenue (**22,711,986**) and the highest profit (**8,330,376**).

### Region
Africa recorded the highest number of transactions with **818 transactions**.
